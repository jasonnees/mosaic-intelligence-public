# Mosaic Income brand asset

`mosaic-income-wordmark.png` is the original transparent wordmark displayed by the user's Mosaic Income Substack at https://mosaicincome.substack.com/.

Source inspected October 22, 2026:
https://substack-post-media.s3.amazonaws.com/public/images/61bb6564-4cb3-4d93-9a0a-e50ce11b0501_3162x621.png

The downloaded image is not recolored or redrawn. The dashboard uses a CSS brightness adjustment to make it legible against the dark background. The cyan, violet, amber, blue, rose and mint chart colors extend the site's blue brand palette for dashboard use; they are not claimed to be official Substack brand colors.

`boldin-wordmark.svg` is the unmodified inline wordmark from https://www.boldin.com/, retrieved October 31, 2026. The active app uses Boldin branding. The original Mosaic image remains for history.
